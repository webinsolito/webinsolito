Motore locale non connesso

Cosa vuoi fare?

Questa è l'interfaccia del programma NEURA. I comandi che richiedono Windows vengono eseguiti solo quando il motore locale è collegato: nessuna azione viene simulata o dichiarata completata senza verifica.

Il browser è solo l'interfaccia. Le azioni sul PC richiedono il motore NEURA locale collegato.

Attività

Registro locale dell'interfaccia. Le azioni Windows appariranno qui solo dopo esecuzione verificata dal motore locale.

Nessuna attività eseguita

Il motore locale non è ancora collegato a questa interfaccia.

Memoria

Il Memory Retrieval Fabric C9.53 è il backend previsto per questa sezione. La pagina non inventa ricordi se il motore locale non risponde.

Ricerca ibrida

BM25 + semantic + entity + temporal.

Fail-soft

Se gli embedding non sono disponibili, il retrieval lessicale resta operativo nel motore locale.

Stato backend

Non collegato.
